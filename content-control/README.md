# Forexin Content Control Center

این بخش مرکز کنترل تولید محتواست. هر منبع آموزشی یک Content Package دارد که شامل مقاله، پادکست، ریلز، قلاب‌ها، کاور پیشنهادی، نسخه‌های اختصاصی پلتفرم‌ها، منابع و امتیاز کنترل کیفیت است.

## وضعیت‌ها

- `draft`: پیش‌نویس تولید شده و نیازمند بررسی است.
- `approved`: مدیر آن را تأیید کرده است.
- `rejected`: نیازمند اصلاح است.
- `published`: انتشار نهایی ثبت شده است.

## سیاست انتشار

سایت می‌تواند طبق Workflow فعلی منتشر شود. نسخه‌های Instagram، Telegram، WhatsApp، TikTok، YouTube، LinkedIn و X ابتدا به‌صورت پیش‌نویس ذخیره می‌شوند و ارسال عمومی خودکار یا پیام‌دادن به کاربران ناشناس فعال نیست.

## فازهای بعدی

1. داشبورد و دکمه‌های تأیید در ربات
2. اتصال کتابخانه دانش و جلوگیری از تکرار موضوع
3. تولید ریلز، زیرنویس و کاور واقعی
4. تحقیق منابع عمومی، تحلیل رقبا و تقویم محتوا
5. تحلیل قیف جذب، لینک‌های قابل‌اندازه‌گیری و گزارش هفتگی
